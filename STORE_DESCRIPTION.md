# Chrome Web Store Description

## Short description (132 char max)

Pitch-shift audio on any tab in real time — up to ±12 semitones. Perfect for singers, musicians, and language learners.

## Full description

Pitch Shifter lets you raise or lower the pitch of any audio playing in Chrome — YouTube, Spotify Web, SoundCloud, podcasts, video calls — without affecting playback speed.

HOW TO USE
• Click the extension icon while audio is playing
• Drag the slider, scroll the mouse wheel, or use the +/− buttons to shift pitch by semitone
• The toolbar badge shows your current pitch at a glance
• Hit Reset to return to normal pitch instantly

FEATURES
✓ Works on any tab — YouTube, Netflix, Spotify Web, SoundCloud, Twitch, and more
✓ Smooth real-time pitch shifting with no playback interruption
✓ Mouse wheel support on both the slider and the number input
✓ Per-tab pitch memory — each tab keeps its own setting
✓ Toolbar badge shows active pitch (+3, −2, etc.) at a glance

GREAT FOR
• Singers practicing along to songs in a different key
• Musicians transcribing or learning by ear
• Language learners slowing down and adjusting foreign-language audio
• DJs and producers previewing how tracks fit together

PRIVACY
All audio processing happens entirely on your device. No audio is ever recorded, transmitted, or stored. The extension requires the "Tab Capture" permission solely to route audio through the pitch-shifting engine locally.
